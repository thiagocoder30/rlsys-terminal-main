# RL.Sys Change Approval Flow

Version: 1.0.0

---

# Change Categories

## Feature

Requires:

- feature template
- tests
- validation


## Bug Fix

Requires:

- reproduction
- root cause
- regression test


## Refactor

Requires:

- behavior preservation
- existing tests


## Architecture Change

Requires:

- ADR
- approval before implementation

---

# Approval Principle

No code change has authority over architecture.

Architecture defines acceptable implementation.
