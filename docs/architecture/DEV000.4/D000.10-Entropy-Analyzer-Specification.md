# D000.10 — Entropy Analyzer Specification

**Programa:** DEV000.4 — Decision Intelligence Core

**Status:** Architecture Approved

**Versão:** 1.0

---

# Objetivo

O Entropy Analyzer é o primeiro componente da Feature Layer.

Sua responsabilidade é medir o nível de dispersão estatística presente na sequência de giros da mesa.

Ele transforma uma sequência bruta de números em uma métrica interpretável pelo Decision Engine.

---

# Princípio Arquitetural

O Entropy Analyzer responde exclusivamente:

> "Qual é o grau de aleatoriedade observado na amostra atual?"

Ele não responde:

- qual estratégia utilizar;
- quando entrar;
- quanto apostar;
- se existe vantagem.

Essas responsabilidades pertencem a camadas superiores.

---

# Localização Arquitetural

```
DecisionContext

↓

Feature Layer

↓

Entropy Analyzer

↓

Feature Result

↓

Strategy Score Engine

↓

Decision Engine
```

---

# Responsabilidade

O módulo possui quatro responsabilidades:

```
1. Coletar distribuição dos números

2. Calcular entropia estatística

3. Classificar o estado da mesa

4. Fornecer explicação interpretável
```

---

# Entrada

O analisador recebe somente a sequência histórica.

Contrato:

```
timeline: number[]
```

Exemplo:

```
[
17,
34,
6,
17,
22,
0,
17
]
```

---

# Saída

O resultado deve seguir um contrato padronizado.

Exemplo:

```
EntropyResult
{
    value: number,

    normalized: number,

    classification: string,

    confidence: number
}
```

---

# Campo Value

Representa a entropia matemática calculada.

Método recomendado:

Entropia de Shannon.

Fórmula:

```
H(X) = - Σ p(x) log₂ p(x)
```

Onde:

```
p(x)
```

representa a frequência relativa de cada número.

---

# Campo Normalized

A entropia bruta deve ser convertida para uma escala operacional.

Escala:

```
0 - 100
```

Objetivo:

Permitir comparação entre diferentes analisadores.

Exemplo:

```
0

Mesa extremamente concentrada


100

Mesa extremamente dispersa
```

---

# Classificação

A classificação transforma o número em uma interpretação operacional.

Estados:

```
COLLAPSED

NORMAL

ACTIVE

CHAOTIC
```

---

# COLLAPSED

Características:

- baixa diversidade;
- alta concentração;
- repetição elevada.

Interpretação:

```
Mesa concentrada.
Necessária validação adicional.
```

---

# NORMAL

Características:

- distribuição equilibrada;
- comportamento esperado.

Interpretação:

```
Mesa dentro do padrão operacional.
```

---

# ACTIVE

Características:

- maior movimentação estatística;
- sinais mais fortes.

Interpretação:

```
Mesa apresenta sinais relevantes.
```

---

# CHAOTIC

Características:

- alta dispersão;
- baixa concentração.

Interpretação:

```
Ambiente estatisticamente instável.
Exigir maior confiança para decisão.
```

---

# Confidence

O analisador deverá informar sua própria confiança.

A confiança considera:

- tamanho da amostra;
- estabilidade da distribuição;
- quantidade de observações.

Exemplo:

Poucos giros:

```
confidence = 0.30
```

Grande histórico:

```
confidence = 0.90
```

---

# Regras de Implementação

## Regra 1

O Entropy Analyzer deve ser uma função pura.

Mesmo:

```
input
```

deve produzir sempre:

```
output
```

idêntico.

---

## Regra 2

Não pode possuir estado interno.

Proibido:

- cache;
- LocalStorage;
- React State;
- variáveis globais.

---

## Regra 3

Não pode conhecer estratégias.

Proibido:

```
if(strategy === ...)
```

---

## Regra 4

Não pode gerar decisão.

Proibido:

```
return ENTER
```

ou:

```
return BET
```

---

# Tratamento de Dados Insuficientes

Caso a amostra seja insuficiente:

Exemplo:

```
timeline.length < 10
```

O módulo deve retornar:

```
classification:

INSUFFICIENT_DATA
```

e confiança reduzida.

---

# Testes Obrigatórios

O módulo deverá possuir testes cobrindo:

## Teste 1

Sequência totalmente repetida.

Entrada:

```
[
17,
17,
17,
17
]
```

Esperado:

```
baixa entropia
```

---

## Teste 2

Sequência distribuída.

Entrada:

```
0 até 36
```

Esperado:

```
alta entropia
```

---

## Teste 3

Poucos dados.

Esperado:

```
confidence reduzida
```

---

## Teste 4

Determinismo.

Mesma entrada:

```
mesmo resultado
```

---

# Integração com Decision Engine

O Decision Engine utilizará:

```
entropy.normalized
```

para ajustar:

- exigência mínima de confiança;
- agressividade da decisão;
- filtro de risco.

Exemplo:

Alta entropia:

```
necessita maior confiança
```

Baixa entropia:

```
permite análise normal
```

# Evolução Futura

Possíveis extensões:

```
├── WeightedEntropyAnalyzer

├── TemporalEntropyAnalyzer

├── BayesianEntropyModel

└── AdaptiveEntropyThreshold
```

Essas evoluções não alteram o contrato atual.

---

# Benefícios

O Entropy Analyzer fornece:

- medição objetiva da aleatoriedade;
- explicabilidade;
- redução de decisões emocionais;
- base matemática para filtros de risco;
- componente independente para testes.

---

# Regra Institucional

O Entropy Analyzer produz evidência.

Ele nunca produz decisão.

A decisão pertence exclusivamente ao:

```
Decision Engine
```
