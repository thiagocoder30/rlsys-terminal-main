DEV000.4 — Decision Intelligence Core

D000.27 — Decision Core Dependency Map

Status: Architecture Analysis Document
Módulo: Decision Intelligence Core
Objetivo: Mapear todas as dependências necessárias para implementação segura do Decision Core.

---

1. Objetivo

Este documento define o mapa de dependências arquiteturais entre o estado atual do RL.SYS CORE e o novo módulo Decision Intelligence Core.

A finalidade é identificar:

- fontes de dados;
- componentes consumidores;
- pontos de integração;
- contratos existentes;
- riscos de acoplamento.

O Decision Core deve ser introduzido como um domínio independente.

---

2. Princípio de Dependência

A arquitetura deve seguir:

Componentes externos
        |
        v
Decision Context
        |
        v
Decision Intelligence Core
        |
        v
Decision Result
        |
        v
Consumidores

O Decision Core deve:

- receber dados;
- processar inteligência;
- devolver decisão.

Ele não deve controlar origem ou destino dos dados.

4. Dependência: Spin Ingestion

Responsabilidade Atual

Responsável pela entrada de novos resultados da roleta.

Produz:

- número sorteado;
- sequência temporal;
- atualização de histórico.

---

Relação com Decision Core

Entrada indireta:

timeline[]

Destino:

DecisionContext.timeline

---

Regra Arquitetural

Decision Core não deve conhecer:

- websocket;
- provider;
- captura de spin;
- mecanismo de entrada.

Ele recebe somente dados processados.

---

7. Dependência: Estratégias Existentes

Estado Atual

- regras próprias;
- critérios;
- pesos;
- histórico.

17. Estratégia de Integração

A integração deve seguir:

Primeiro

Criar Decision Core independente.

---

Segundo

Criar Adapter.

Exemplo:

DecisionContextAdapter

Responsável por converter estado atual para novo contrato.

---

Terceiro

Integrar runtime.

---

18. Critérios de Segurança

Durante implementação:

- nenhuma dependência circular;
- nenhum import de UI;
- nenhum acesso global;
- nenhum estado mutável externo.

---

19. Resultado Esperado

Após conclusão:

O Decision Core será um módulo isolado:

RL.SYS CORE

        |

        +-- Runtime

        +-- HUD

        +-- Strategies

        +-- Decision Intelligence Core
