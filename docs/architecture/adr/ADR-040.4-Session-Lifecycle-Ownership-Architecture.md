ADR-040.4 — Session Lifecycle Ownership Architecture (SLOA)

Status: ACCEPTED

Sprint: HOTFIX ARQUITETURAL

Tipo: Architecture Stabilization

Data: 29/07/2026

---

CONTEXTO

Durante a investigação arquitetural do fluxo de inicialização do RL.SYS CORE foi identificada uma inconsistência estrutural no gerenciamento do ciclo de vida das sessões operacionais.

O problema observado não está relacionado exclusivamente ao frontend ou ao mecanismo de polling.

A causa raiz encontra-se na ausência de um ciclo de vida completo da entidade Session.

Atualmente o sistema permite iniciar e finalizar uma sessão, porém não possui mecanismos institucionais para:

- retomar uma sessão existente;
- limpar uma sessão ativa;
- arquivar uma sessão finalizada;
- distinguir estados transitórios do Runtime.

Essa lacuna faz com que o Bootstrap não consiga determinar corretamente qual fluxo operacional deve ser iniciado.

Como consequência, o Startup Wizard entra em conflito com o SessionControlEngine, ocasionando reentrada no Bootstrap e loops de interface.

---

DECISÃO

Introduzir uma camada institucional denominada Session Lifecycle Ownership.

Esta camada será a única responsável pelo gerenciamento completo do ciclo de vida das sessões.

Nenhum componente do sistema poderá alterar diretamente o estado de uma sessão.

Toda transição deverá ocorrer exclusivamente através do SessionLifecycleManager.

---

OBJETIVOS

Criar um ciclo de vida institucional completo para sessões.

Eliminar ambiguidades entre Bootstrap, Startup Wizard e SessionControlEngine.

Garantir existência de uma única fonte de verdade para o estado da sessão.

Preparar a arquitetura para Persistência (Sprint-049).

Preparar Backup & Restore (Sprint-050).

Preparar sincronização futura entre dispositivos.

---

SESSION LIFECYCLE MANAGER

Responsabilidade exclusiva:

- criar sessão;
- iniciar sessão;
- pausar sessão;
- retomar sessão;
- finalizar sessão;
- arquivar sessão;
- limpar estado transitório.

Nenhum outro módulo poderá alterar estados diretamente.

---

SESSION CONTROL ENGINE

Deverá deixar de controlar diretamente o ciclo de vida.

Passará a consumir exclusivamente o SessionLifecycleManager.

O SessionControlEngine continuará responsável apenas por:

- banca;
- stake;
- stop loss;
- stop win;
- progresso operacional.

IMPACTO ARQUITETURAL

Esta ADR não altera:

- IntelligenceRuntime;
- QuantitativeEnginePipeline;
- Recommendation Engine;
- Institutional AI;
- Session Intelligence;
- Session Audit;
- Paper Trading;
- Decision Engine.

A alteração restringe-se exclusivamente ao gerenciamento institucional do ciclo de vida das sessões.

---

RESULTADO ESPERADO

Após a implementação desta ADR:

- o Bootstrap executará apenas uma vez por inicialização;
- o Startup Wizard não entrará em loop;
- "Continuar Sessão" retomará corretamente uma sessão ativa;
- "Nova Sessão" encerrará e arquivará a sessão anterior antes de iniciar outra;
- o Runtime possuirá uma única fonte de verdade para o estado da sessão;
- a arquitetura ficará preparada para Persistência, Backup & Restore e sincronização futura entre dispositivos.

---

DECLARAÇÃO FINAL

A Session Lifecycle Ownership Architecture estabelece um modelo institucional único para o gerenciamento do ciclo de vida das sessões operacionais do RL.SYS CORE.

Com esta arquitetura, elimina-se a duplicidade de responsabilidades entre Bootstrap, Startup Wizard e SessionControlEngine, consolidando uma única autoridade para transições de estado e preparando a plataforma para as próximas fases do roadmap institucional.
