====================================================================
GOVERNANCE RULES
====================================================================

DecisionSummary shall never be modified after creation.

Explainability consumes DecisionSummary in READ-ONLY mode.

Explainability shall never invoke quantitative engines.

Explainability shall never modify rankings.

Explainability shall never modify scores.

Explainability shall never modify probabilities.

Every execution shall enter through IntelligenceRuntime.

DecisionAuditLedger stores only finalized executions.

The PUBLIC API is governed by the PUBLIC API FROZEN policy.

Breaking changes require a new ADR.

====================================================================
ARCHITECTURAL GUARANTEES
====================================================================

XAI does not recalculate quantitative engines.

DecisionSummary remains immutable.

Explainability is a downstream bounded context.

IntelligenceRuntime is the Single Point of Execution.

DecisionAuditLedger stores immutable execution evidence.
